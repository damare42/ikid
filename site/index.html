Why local-first

The safest place for your financial data is your own computer.

ikid has nothing to leak, by design.

  • No bank credentials. You export statements yourself — ikid never asks for logins and has no aggregator.
  • No cloud account. Everything lives in a SQLite file on your machine.
  • No third-party calls. No analytics SDKs, no ad networks, no telemetry to us. This page doesn't make any either — no fonts, no scripts, no trackers.
  • Optional AI stays local. Install Ollama and the planner answers freeform questions on your own hardware — or skip it and the deterministic engine still does the maths.
  • No lock-in. One click exports everything to readable JSON that references categories and accounts by name, so it opens in a text editor and imports anywhere.
  • Open source. Read every line. The privacy claim is architectural, not a promise you have to trust.

Read the principles, the security policy, and the export format.

Get started

Running in about five minutes

You'll need Node.js 20+. Everything below runs on your own machine — there is no ikid server to sign up for.

Clone and run

The straightforward path. Open http://localhost:3001 when it finishes.

git clone https://github.com/damare42/ikid.git
cd ikid
npm install
npm run build
npm start

Docker (self-host)

For a home server or a private VPS. Sign-in is required by default and data persists in a named volume.

docker compose up -d

# optional: add a local Ollama for the planner
docker compose --profile ai up -d
  1. Sign up — the account is local to your machine, not an ikid account.
  2. Export a CSV or PDF statement from your bank and drop it in. Review the categories, then commit.
  3. Set budgets and goals, then ask the planner what happens if you buy a house — or retire at 45.

Desktop installers are not published yet. Packaging for macOS, Windows and Linux is built and working, but the builds are unsigned, so they'll land on the releases page once signing is sorted. Until then, the two commands above are the supported way in.

Honest limitations

What ikid is not

Not automatic

There's no bank sync — you export statements yourself. That's the trade for never sharing credentials.

Not tax advice

The retirement and tax tools use real federal tables and are unit-tested, but they're planning support. Confirm decisions with a professional.

Not a hosted service

There's no ikid server holding your data. If you want access from anywhere, you host it yourself.

Not finished

It's early. Expect rough edges, and expect the changelog to move quickly.

Not multi-currency

You can pick a display currency, but there's no conversion between currencies in one profile yet.

Not audited

The security design is documented and the claims are tested, but no third party has reviewed it. Read the code.
