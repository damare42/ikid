Design review · August 2026

Shipped build vs.
Modernist redesign

An honest read on both directions — what each one buys, what it costs, and what the redesign still has to earn before it replaces the build that already works.

The short version

verdict
Current build wins on
Density and familiarity
Card grids, coloured badges and emoji anchors let you find a number without reading. Recharts gives real tooltips for free. It is also the only version that exists in code.
Redesign wins on
Hierarchy and trust
Ledger tables, one accent and typographic hierarchy read as a financial instrument rather than a dashboard template. Navigation finally scales past nine screens.
Recommendation
Adopt the redesign, port three habits back
Keep chart interactivity, colour-coded categories and the tightest mobile density from the current build. Those are the three places it is genuinely better, not just older.

Current build

Tailwind · slate + green
Pros
01It exists and it is finishedThirteen working pages, real parsing, learned rules, undo. Every hour spent restyling is an hour not spent on the import review flow.
02Cards are forgivingA card grid absorbs a missing field or an extra stat without breaking. Ruled rows expose every inconsistency in the data.
03Colour does real workEmerald income, rose overspend, amber staleness, per-category badge colour — three of those encode meaning the mono palette has to re-earn with words.
04Free interactivityRecharts tooltips, legends and responsive containers already answer "what was March?" — the redesign's SVG charts do not yet.
05Mobile by defaultEverything is a stack of cards, so the phone case needed no separate design.
Cons
01No hierarchyEvery page opens with the same 20px bold title over identical cards, so nothing tells you what matters. Retirement and Groceries carry equal weight.
02AnonymousDefault Tailwind slate, one green, rounded boxes — it looks like every side-project finance app, which is a trust problem when the subject is money.
03Emoji as an icon system🏦🐷💳 render differently per platform, carry no state, and cannot be recoloured or aligned.
04Navigation ran out of roomAccounts had no home; the top bar was already full before Retirement and Reports arrived.
05Colour overloadEmerald, rose, amber, brand-green and per-category badges compete on one screen; when everything signals, nothing does.

Modernist redesign

Archivo · ink + one red
Pros
01Reads like a ledgerTabular figures, right-aligned amounts, hairline rules. Money data belongs in rows, and comparison down a column is instant.
02Hierarchy you can feelKicker, display headline, section rule, quiet body. The eye lands on the number that matters first — on all thirteen screens, the same way.
03Navigation that scalesGrouped sidebar (Money / Plan / Insight) with identity pinned top-right — the model Mercury, YNAB and Copilot converged on. Room for the next five screens.
04One accent, so it means somethingRed marks the primary action and the thing that is off-plan. Overspend actually stands out because nothing else is coloured.
05Identity end to endThe waypoint mark, splash, landing page and app now share one voice — and the type prints, exports and screenshots cleanly.
Cons
01Lower density, more scrollingRuled rows and generous section spacing show roughly two-thirds of what the card grid showed per fold.
02Mono palette drops a channelCategory colour and income green were doing legitimate encoding work. Tags now read by name, which is slower at a glance.
03Red is loud in financeThe accent already reads as "loss" to a money user; toning it to #c62f14 helped, but every red element competes with that instinct.
04Charts are drawings, not componentsThe SVG curves look better and do less — no tooltips, no hover, no responsiveness until they are rebuilt properly.
05Wide tables fight the phoneEight-column transaction ledgers need a purpose-built mobile row, not a reflow. That is design work the card version never needed.
06It is a full portEvery page, every shared component, both themes, plus the underline-field and hairline conventions — a rewrite of the view layer, not a theme swap.

What to carry across

before the redesign ships
01 · Restore
Chart interactivity
Hover readouts and a value tooltip on every SVG chart. Pretty is not worth losing "what was March?".
02 · Done
The colour channel, merged in
Category swatches on every tag, hue-matched budget bars, and green income / red overspend as real semantic tokens in both themes. Emoji anchors were tried and dropped — the colour channel carries the scanning work on its own.
03 · Design
Mobile ledger rows
Two-line rows with the amount pinned right, not a squeezed table. Currently only the desktop ledgers are resolved.
04 · Add
A density switch
The dense prop exists — make it real on the ledger screens so power users can get the card grid's information rate back.
